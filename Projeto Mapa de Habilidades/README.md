# 🚀 Mapa de Habilidades - DIO

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da plataforma DIO (Digital Innovation One).

O objetivo foi realizar um mapeamento das minhas competências, identificar oportunidades de mercado e explorar possibilidades de monetização utilizando Inteligência Artificial como ferramenta de apoio.

Durante a atividade utilizei IA para:

- Identificar habilidades técnicas e comportamentais;
- Pesquisar tendências do mercado;
- Relacionar competências com oportunidades profissionais;
- Organizar as informações em formato de documentação.
